# Sistema de Gestión de Pedidos y Producción para una Mueblería

Proyecto desarrollado para la asignatura Seminario.

## Tecnologías utilizadas

- Java
- MySQL
- JDBC
- Git
- GitHub

## Estructura del repositorio

### AP1
Contiene el informe correspondiente a la Actividad Práctica 1.

### AP2
Contiene el informe correspondiente a la Actividad Práctica 2 y el script de creación de la base de datos.

### GestionMuebleria
Prototipo del sistema desarrollado en Java.

## Funcionalidades previstas

- Gestión de clientes
- Gestión de pedidos
- Gestión de pagos
- Seguimiento de producción
- Consulta de saldos
- Registro de entregas
